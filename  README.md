# ⚔️ Text Fighter - Monkey King vs Percy Jackson

A fully-featured text-based fighting game built with Flask, featuring deep combat mechanics, status effects, super meter system, positioning, and unique character abilities.

## 🎮 Game Features

### Characters
- **🐒 Monkey King** - Agile trickster with evasion and clone abilities
- **🌊 Percy Jackson** - Tanky water controller with healing and water empowerment

### Combat System
- **Full Status Effects**: Stun, Burn, Poison, Empower, Weaken, Armor, Bleeding, Frozen, Confused
- **Super Meter System**: Build meter by dealing/taking damage, spend on special moves and supers
- **Positioning System**: Close, Medium, Far ranges affect move availability
- **Combo System**: Chain attacks for increased damage
- **Unique Abilities**: Trickster's Advantage (Monkey King) and Water Empowerment (Percy Jackson)

### Game Modes
- Player vs CPU with advanced AI
- Best of 3 rounds match format
- Full status effect tracking
- Real-time battle log
